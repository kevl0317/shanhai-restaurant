# 山海食谱铺 · 菜品美术资源 v1

本包按 `03_山海食谱铺_网游开发脚本.docx` 整理和绘制，共 29 道独立菜品：25 道地方名菜及 4 道全章节共用菜。

## 使用入口

- `00-全菜品总览.png`：带中文菜名的全部菜品总览。
- `index.html`：双击可打开本地图鉴；支持菜系筛选、搜索、切换背景、查看及下载图片。
- `images/`：内置 image_gen 生成的原始透明 PNG，保留生成尺寸。
- `sprites-1024/`：统一 1024×1024 透明 PNG，用于图鉴大图、菜卡和摆宴。
- `icons-256/`：统一 256×256 透明 PNG，用于常规菜品架与订单。
- `icons-128/`：统一 128×128 透明 PNG，用于小尺寸预览。
- `manifest.json`：包含每道菜的名称、菜系、识别要点、图片路径、原图尺寸、透明通道检查、SHA-256 及各导出版本。
- `catalog.json`：按原脚本顺序排列的基本目录；01–25 对应关卡，26–29 为共用菜。
- `prompts/`、`style.txt`：每道菜实际使用的完整提示词及公共风格要求。
- `provenance-*.json`：原始生成文件来源记录。

## 绘制规格

使用内置 **image_gen** 逐道生成，以白切鸡为系列风格参考。整体采用细腻食物手绘、柔和立体明暗、米白与浅青边瓷器、俯视三分之四视角。每张图只保留一道菜及其器皿，背景使用真实 alpha 透明通道。图内不烘焙文字，中文名称由界面显示。

程序导出仅做等比尺寸缩放和透明留白，未重新绘制或替换食物细节。原始生成图始终保存在 `images/`。

## 游戏接入

1. 看单、换单、配单、反馈始终引用同一菜品 ID 与同一图像，避免额外视觉差异影响记忆任务。
2. 每章资源池由该章 5 道特色菜与 26–29 四道共用菜组成，共 9 张。共用菜不标记为某个菜系独有。
3. 菜名使用完整中文名称并允许换行；图像展示建议 `object-fit: contain`，保留器皿边缘。
4. 正式计时前完成该章 9 张图片的预加载。
5. 未额外绘制选中、禁用、正确与错误版本；这些交互状态可复用同一图片，由界面轮廓与文字呈现。

## 导出复现

安装 Node.js 与 `sharp` 后运行 `node build-delivery.cjs`。脚本优先使用普通模块解析，并兼容本机 Codex 自带依赖路径。它会先确认 29 张原图齐全且具有真实透明通道，再生成标准图、小图标、清单和总览。后续修订应新建版本目录，以保留本次成果。
